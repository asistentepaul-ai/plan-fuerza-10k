# Plan de Fuerza 10K — Anti-cintilla

Plan de fuerza guiado (PWA con temporizador) para erradicar el **ITBS recurrente** (cintilla iliotibial) y sostener la progresión a 10K.

## Uso

Abre la app (GitHub Pages), "Añadir a pantalla de inicio" en el móvil → funciona offline.

- **Sesión A — Cadera:** monster walks, clamshell con banda, puente a una pierna, plancha lateral.
- **Sesión B — Variante:** donkey kick, abducción lateral, hip thrust, plancha frontal.
- 2-3 sesiones/semana · bloque de 8-12 semanas · progresión por resistencia de banda.

## Reglas

1. Progresión por banda: cuando 3×15 sea fácil → banda más resistente.
2. Dolor = parar ese ejercicio. Agujetas normal; dolor en inserción de cintilla NO.
3. 0 dolor de cintilla al correr = criterio maestro (ver Plan 10K en el vault).
4. Calentar 5 min antes (caminata + movilidad de cadera).
